# Aethery v2.0.0

Aethery v2.0.0 moves the bundled Aether core from v1.9.0 to v2.4.0, adds Tor, Psiphon and two new WARP-on-WARP and MASQUE methods, and replaces the whole interface with a new one.

## In this release

**Core (Aether v2.4.0)**

• Updated the vendored Aether core from v1.9.0 to v2.4.0.
• **WARP-on-WARP over MASQUE.** A WireGuard tunnel carried inside a MASQUE tunnel, so Cloudflare sees the MASQUE edge instead of your address and hands the inner tunnel a different exit IP. This is the new default WARP-on-WARP. The older nested WireGuard mode is still there as **WARP-on-WARP (WireGuard)**.
• **MASQUE-on-MASQUE.** A MASQUE tunnel inside another MASQUE tunnel, for a different exit address. It serves the local SOCKS5 and HTTP CONNECT proxies, so it works in Proxy mode only.
• **Tor and Psiphon.** Tor is built into the core and Psiphon's client ships inside the APK. Use either one to carry the tunnel, run inside it as a second proxy, or stand alone. See *Tor and Psiphon* below.
• **Registration is harder to block.** The WARP API is called by `api.devices.cloudflare.com` and falls back to Cloudflare edge addresses and the older name when the first gets no answer. A new identity is saved only once WARP is enabled on it, and a saved identity is never asked about again. `--api-address`, `--api-sni` and `--api-host` replace `--enroll-address`.
• MASQUE handshakes send `www.cloudflare.com` as the server name by default; `--masque-sni` changes it. `--tls-verify` holds the MASQUE gateway to the certificates Aether carries.
• New TLS fingerprint options, now in the app: TLS 1.3 cipher suites, key shares, GREASE for signature algorithms, signature algorithms, certificate compression (zlib, brotli, zstd), ALPS, trust anchor IDs, server padding, GREASE ECH, and switches to leave out OCSP, SCT, session tickets and extension reordering.
• Scans cover more of regular WARP's MASQUE gateways, over IPv4 and IPv6.
• A gateway or WireGuard endpoint whose tunnel keeps ending soon after it starts is left out of scans for a while instead of being picked again.
• The SOCKS5 and HTTP CONNECT ports are held for the whole run, so they stay yours while the tunnel reconnects.

**Android app**

• **A new interface.** The main screen is built around a connect orb over a sky that goes from dusk to dawn when you connect. The orb reacts to touch, tilt and state with spring motion and haptics, and everything holds still if the system has animations turned off.
• **Every page was rebuilt** in the same style, with one transition. Pop-ups and dialogs are now full pages with a back button in the top corner, including choices, editors and the update flow.
• **A bundled font** (Manrope) replaces the device font, and the default theme is the new Halo theme. The other themes stay.
• **Connecting shows what is happening**: the real stage, such as "Registering with Cloudflare" or "Finding a verified MASQUE gateway".
• **Tap the orb while connecting to cancel.** Cancelling stops a registration in progress at once.
• **Registration no longer takes your other VPN down.** Aethery now registers every identity a method needs first, and only then asks for VPN permission. Asking for that permission is what drops any VPN that is up, and some networks need one for the one-time registration. This also covers the tile and widgets.
• New options in **Settings → Tunnel controls**:
  – **Carrier**: Direct, Through Tor, Tor inside the tunnel, Tor alone, and the same three for Psiphon, plus Tor country, Tor bridges and Psiphon region.
  – **Registration**: API address, server name and host.
  – **Routing**: exit country, which keeps looking until the tunnel comes out where you want.
  – **Handshake**: TLS fingerprint, Encrypted Client Hello, MASQUE server name, certificate check, GREASE, and **Advanced TLS** with every option above.
  – **MASQUE**: HTTP/3 → HTTP/2 fallback, QUIC v2 opener, TLS fragmentation with size and delay, quick reconnect.
  – **WireGuard**: retries, strict verification, keepalive.
• Two new obfuscation profiles, **Firewall** and **GFW**.

## Tor and Psiphon

Open **Settings → Tunnel controls → Carrier**.

• **Through Tor / Through Psiphon** dials the tunnel over Tor or Psiphon, so your network never sees WARP. These carry TCP only, so they work with the MASQUE-based methods and refuse WireGuard and WARP-on-WARP (WireGuard).
• **Tor / Psiphon inside the tunnel** adds a second proxy: `127.0.0.1:1822` for Tor, `127.0.0.1:1821` for Psiphon. The usual proxy keeps the WARP exit.
• **Tor alone / Psiphon alone** has no WARP and no VPN. It is a local proxy that leaves through Tor or Psiphon, and the app switches to Proxy mode for it.

Tor and Psiphon can take a minute or more to start, and longer where they are blocked.

## Methods

The method list now has five entries: MASQUE, WireGuard, WARP-on-WARP (WireGuard), WARP-on-WARP (MASQUE) and MASQUE-on-MASQUE. The widgets cycle through all of them except MASQUE-on-MASQUE, which needs Proxy mode.

## Updating

v2.0.0 is signed with a new key, so Android will not install it over v1.0.0 and the in-app updater cannot replace it. Uninstall v1.0.0 first. Its saved settings and identities go with it, and Aethery registers new identities on the first connection. Releases after v2.0.0 are signed with the same key and update in place.
